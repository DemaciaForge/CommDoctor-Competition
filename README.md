# CommDoctor - 数字通信教学诊断实训平台

## 项目概述

CommDoctor 是一个面向数字通信教学的主动故障诊断与交互式修复实训平台。本项目参加第九届传智杯 AI创新应用挑战赛（Vibe Coding个人赛）。

**核心目标：** 让没有专业实验设备的通信工程学生，通过软件体验数字通信系统中的故障观察、分析、诊断、修复和评价。

## 项目特点

- ✅ 基于真实数字通信数学模型
- ✅ 交互式故障诊断流程
- ✅ 可验证的性能计算
- ✅ 完整的教学反馈机制
- ✅ AI辅助开发全程可追溯
