## 1. 数学错误纠正

### 1.1 阶段02-A文档中的错误声称

阶段02-A设计文档第2.1节声称：

> 在Eb/N0=8dB、DC偏移b=0.4条件下：
> - 修复前BER ≈ 0.15
> - 修复后BER ≈ 0.0002

### 1.2 正确理论推导

对于实值、单位比特能量、等概率BPSK和AWGN模型：

**数学模型:**
```
接收信号: r = s + b + w
其中:
  s ∈ {-1, +1}: BPSK符号
  b: DC偏移
  w ~ N(0, σ²): AWGN噪声
  σ² = 1/(2×Eb/N0)
```

**判决规则:**
```
r >= 0 → 比特1
r < 0  → 比特0
```

**理论BER推导:**
```
P(错误|发送-1) = P(r >= 0 | s=-1)
                = P(-1 + b + w >= 0)
                = P(w >= 1-b)
                = Q((1-b)/σ)

P(错误|发送+1) = P(r < 0 | s=+1)
                = P(+1 + b + w < 0)
                = P(w < -1-b)
                = Q((1+b)/σ)

BER = 0.5 × [Q((1-b)/σ) + Q((1+b)/σ)]
```

其中 Q(x) = 0.5 × erfc(x/√2)

**Eb/N0 = 8 dB, b = 0.4 的计算:**
```
Eb/N0 (线性) = 10^(8/10) = 6.3096
σ = sqrt(1/(2×6.3096)) = 0.28150428

(1-b)/σ = (1-0.4)/0.28150428 = 2.1314
(1+b)/σ = (1+0.4)/0.28150428 = 4.9733

P(错误|s=-1) = Q(2.1314) = 0.0165278415
P(错误|s=+1) = Q(4.9733) = 0.0000003291

BER = 0.5 × (0.0165278415 + 0.0000003291) = 0.0082640853
```

**完美消除DC偏移后 (b=0):**
```
BER = Q(sqrt(2×Eb/N0)) = Q(sqrt(2×6.3096)) = Q(3.5525)
    = 0.0001909078
```

### 1.3 实验验证

使用100000比特的Monte Carlo仿真验证理论值：

| 条件 | 理论BER | 实测BER | 偏差 |
|------|---------|---------|------|
| 修复前 (b=0.4) | 0.0082640853 | 0.0077400000 | 6.34% |
| 修复后 (b=0) | 0.0001909078 | 0.0001900000 | 0.48% |

实测BER与理论值吻合良好，偏差在统计波动范围内。

### 1.4 错误原因分析

阶段02-A文档可能混淆了以下概念：
1. **DC偏移大小与BER的关系：** 实际上，b=0.4的DC偏移在8dB信噪比下并不会导致BER达到0.15
2. **错误率不对称性：** 虽然DC偏移导致P(0→1)和P(1→0)不对称，但总BER仍然较低
3. **未进行数值验证：** 设计阶段未通过仿真验证理论计算

**纠正行动：**
- ✅ 独立推导并验证理论BER公式
- ✅ Monte Carlo仿真验证理论值
- ⚠️ 需更新阶段02-A文档中的数值示例

## 3. 训练与评价数据隔离

### 3.1 隔离机制

**设计原则：**
训练数据仅用于DC估计，评价数据用于性能验证，两者完全独立。

**实现方法：**
```python
# 训练阶段：使用种子seed_train
train_bits = generate_bits(num_bits_train, seed=seed_train)
train_received = awgn_channel(..., seed=seed_train + 1000)
dc_estimate = estimate_dc_offset(train_received, training_bits=train_bits)

# 评价阶段：使用不同种子seed_eval
eval_bits = generate_bits(num_bits_eval, seed=seed_eval)  # 完全不同的数据
eval_received = awgn_channel(..., seed=seed_eval + 1000)

# 修复：使用训练阶段得到的DC估计值
eval_corrected, _ = remove_dc_offset(eval_received, dc_estimate=dc_estimate)
```

**验证独立性：**
- ✅ 使用不同随机种子生成训练和评价比特
- ✅ 训练阶段不访问评价数据
- ✅ 评价阶段不重新估计DC（使用训练得到的估计值）
- ✅ 明确记录样本数量和种子

### 3.2 为什么需要隔离？

**科研诚信原因：**
如果在同一批数据上既训练又评价，会导致：
- 过于乐观的性能估计
- 无法验证估计器的泛化能力
- 类似机器学习中的"数据泄露"问题

**工程实际原因：**
真实系统中，接收机需要：
1. 用初始训练序列估计系统参数
2. 用估计的参数处理后续未知数据
3. 不能每次都重新校准

### 3.3 实验配置

标准实验使用：
- 训练序列长度：10000比特
- 评价序列长度：100000比特
- 训练/评价种子完全不同

## 4. DC估计方法

### 4.1 方法1：两点法（推荐）

**适用场景：** 有已知训练序列

**数学原理：**
```
对于BPSK符号s ∈ {-1, +1}:
  接收信号 r = s + b + w

分别计算发送-1和+1时的平均接收值：
  E[r | s=-1] = -1 + b + E[w] = -1 + b
  E[r | s=+1] = +1 + b + E[w] = +1 + b

DC偏移是两个均值的中点：
  b = (E[r|s=-1] + E[r|s=+1]) / 2
```

**优点：**
- 精度高，不受数据不平衡影响
- 无偏估计
- 适用于任意0/1比例的训练序列

**实现：**
```python
mask_minus1 = transmitted_symbols == -1
mask_plus1 = transmitted_symbols == +1

mean_minus1 = np.mean(received_symbols[mask_minus1])
mean_plus1 = np.mean(received_symbols[mask_plus1])

dc_estimate = (mean_minus1 + mean_plus1) / 2.0
```

### 4.2 方法2：均值法（简化）

**适用场景：** 无已知训练序列，假设0/1等概

**数学原理：**
```
假设P(s=-1) = P(s=+1) = 0.5:
  E[r] = E[s] + b = 0 + b = b
```

**优点：**
- 实现简单
- 不需要已知发送序列

**缺点：**
- 假设0/1等概，数据不平衡时有偏差
- 如果实际P(0)≠P(1)，估计不准确

**实现：**
```python
dc_estimate = np.mean(received_symbols)
```

### 4.3 估计精度

实验结果（10000训练样本）：

| 真实DC | 估计DC | 误差 | 相对误差 |
|--------|--------|------|----------|
| 0.4 | 0.403870 | 0.003870 | 0.97% |
| 0.1 | 0.102471 | 0.002471 | 2.47% |
| -0.5 | -0.499554 | 0.000446 | 0.09% |

**结论：**
- ✅ DC估计精度优秀，相对误差<3%
- ✅ 正负DC偏移均能准确估计
- ✅ 估计精度不随DC大小显著变化

- 修复后BER显著下降（>97%，中等DC偏移）

### 7.2 技术限制

- 修复后BER仍受Eb/N0限制
- 低SNR下修复后BER仍然较高（这是正确的）

⚠️ **均值法假设0/1等概：**
- 如果数据严重不平衡，均值法估计有偏差
- 推荐使用两点法（需要训练序列）

## 附录B：数学公式总结

### DC偏移下的理论BER

**一般公式：**
```
BER(Eb/N0, b) = 0.5 × [Q((1-b)/σ) + Q((1+b)/σ)]

其中:
  σ = sqrt(1/(2×Eb/N0_linear))
  Q(x) = 0.5 × erfc(x/√2)
  Eb/N0_linear = 10^(Eb/N0_dB/10)
```

**特殊情况：**
```
b = 0: BER = Q(sqrt(2×Eb/N0))  (标准BPSK)
b → ∞: BER → 0.5  (完全无法判决)
```

### DC偏移估计

**两点法：**
```
b_estimate = (mean(r|s=-1) + mean(r|s=+1)) / 2
```

**均值法：**
```
b_estimate = mean(r)  (假设P(s=-1)=P(s=+1)=0.5)
```
