### 2.2 推荐的首批3种故障

**推荐顺序（学习路径）：**

1. **符号极性反转（Level 1 - 入门）**
   - BER ≈ 1.0，特征极其明显
   - 诊断简单：BER > 0.5 即可判定
   - 修复效果显著：BER从0.9降到0.001
   - 无歧义性：不与其他故障混淆
   - 适合第一个挑战，建立诊断信心

2. **DC偏移（Level 2 - 核心）**
   - 完整的测量→分析→修复流程
   - 均值测量直观易懂
   - 修复效果好：BER改善 > 90%
   - 引入对称性分析思想
   - 为后续复杂故障奠定基础

3. **判决门限偏移（Level 3 - 进阶）**
   - 与DC偏移对比，展示可辨识性问题
   - 需要多重证据链
   - 培养"证据不足"的识别能力
   - 引入批判性思维

**不推荐首批实现：AWGN噪声功率异常**
- 理由：接收机无法真正修复信道噪声
- 风险：误导学生"所有问题都能修复"
- 替代方案：作为观察型故障（可选的Level 4）

## 三、关键技术发现

### 3.1 DC偏移与判决门限偏移的数学等价性

**核心发现：**
```
接收信号: r[n] = s[n] + b + w[n]
判决规则: r[n] >= t → 比特1

有效判决门限 = t - b

只要 t-b 相同，系统BER相同。
```

**可辨识性结论：**
- 单次测量无法唯一区分b和t
- 需要多重证据：训练序列、门限扫描、对称性检验
- 在某些情况下仍然无法辨识
- 应该允许学生提交"证据不足"诊断

**工程意义：**
- 这不是软件bug，而是物理上的不可区分性
- 真实通信系统中也存在这种等价性
- 具有重要的教学价值：承认不确定性

### 3.2 诊断闭环的隔离原则

**设计原则：**
1. **故障真值隔离** - 诊断模块不能直接读取故障生成器的真值
2. **测量基于真实信号** - 所有测量从实际模拟数据计算
3. **修复基于参数调整** - 明确的信号处理算法，不是魔法修复
4. **公平的性能评估** - 修复前后使用相同信道条件和随机种子

**实现机制：**
```python
class CommunicationScene:
    def __init__(self, fault_config):
        self.fault_config = fault_config  # 私有
        self._ground_truth = {}  # 隐藏
    
    def generate_transmission(self):
        # 只返回接收信号，不暴露真值
        return {"received_symbols": rx_signal}
    
    def verify_diagnosis(self, student_diagnosis):
        # 仅系统内部使用真值验收
        return compare(student_diagnosis, self._ground_truth)
```

### 3.3 统计验证的必要性

**问题：**
单次BER测试受随机性影响，可能出现：
- 修复前碰巧BER较低
- 修复后碰巧BER较高
- 错误判定修复无效

**解决方案：**
- 多次试验（5-10次）
- 每次10,000比特以上
- 配对t检验（p < 0.05）
- 记录置信区间

**验收标准示例：**
```python
result = {
    "ber_before": {"mean": 0.1532, "std": 0.0021},
    "ber_after": {"mean": 0.0002, "std": 0.0001},
    "improvement_ratio": 0.999,
    "statistical_test": {"p_value": 0.0001, "significant": True}
}
```

**风险1：统计波动**
- 强制5-10次独立试验
- 每次10,000比特以上
- 配对t检验，p < 0.05

**风险2：辨识混淆**
- 评分接受任一诊断，只要修复有效

**风险3：暴力尝试**
- 要求提交证据链
- 过程评分占比30%
- 限制尝试次数

## 八、创新点与学术价值

### 8.1 与现有通信教学软件的区别

**传统软件：**
- 展示通信原理演示
- 学生被动观察
- 无故障诊断环节
- 或"伪造"故障（直接显示答案）

**CommDoctor创新：**
- ✓ 真实故障注入（基于数学模型）
- ✓ 学生主动诊断（测量→分析→修复）
- ✓ 故障真值隔离（不能作弊）
- ✓ 完整证据链（过程记录）
- ✓ 统计验证（科学的修复验收）
- ✓ 可辨识性教学（承认不确定性）

### 8.2 教学价值

**核心教学目标：**
1. 培养工程诊断能力
2. 建立测量-分析-修复思维
3. 理解统计不确定性
4. 识别证据不足
5. 接受不可辨识性

**适合人群：**
- 通信工程大一学生（零基础）
- 理论与实践结合的教学场景
- 无专业实验设备的学校
